# Annotated brand kit

Production-ready vector and raster assets for the approved `a.` mark.

## Start here

- Editable vectors: `svg/`
- Transparent PNGs: `png/transparent/`
- App icons: `png/app-icon/`
- Chrome extension icons and manifest snippet: `chrome-extension/`
- Chrome Web Store promotional graphics: `chrome-web-store/`
- Favicon assets: `favicon/`
- Social and GitHub assets: `social/`
- Brand guidelines: `guidelines/annotated-brand-guidelines.pdf`
- Colour tokens: `tokens/`

## Palette

- Charcoal `#212121` / RGB 33, 33, 33
- Terracotta `#C15A45` / RGB 193, 90, 69
- Light grey `#F3F1ED` / RGB 243, 241, 237

## Usage

Use the primary mark on light surfaces and the inverse mark on dark surfaces. Keep one period diameter clear on every side. Do not move or recolour the period.

The SVG logo masters contain literal path geometry and do not depend on an installed font. Font files are not included.
