# Welcome surface — provenance

The motion of this screen was authored against the published timing
measurements for the `speak-language` sequence in
[Appllama/top-welcome-screens](https://github.com/Appllama/top-welcome-screens)
(`docs/MOTION_SPEC.md`), which documents observed onboarding behaviour in
milliseconds.

**No source, asset, or copy from that repository is used here.** That
project is licensed GPL-3.0 and this repository is Apache-2.0; copying its
implementation in would have relicensed this application. Everything in
this directory — the canvas helper, the timeline clock, the interaction
gate, the pressable, and the composition itself — is original code written
for annotated, and `assets/welcome/lower-wash.png` is generated by
[`scripts/generate-welcome-assets.mjs`](../../../scripts/generate-welcome-assets.mjs)
from our own palette.

What was taken is the *structure* of a well-made launch: hold the native
splash until the first frame can be composed, dissolve rather than cut,
stagger the entrance, keep controls inert until their surface has
arrived, and degrade to a composed still under reduced motion. Those are
techniques, not expression.

The name, wordmark, colours, copy, and typography here are annotated's own,
and no affiliation with any referenced application is implied.
